# 演示环境说明

> 演示环境是本机单机栈，**当前未运行**（见「可用性边界」）。本文说明入口、可体验的角色与功能，以及体验时的注意事项。

## 1. 入口

| 入口 | 地址 | 承载什么 |
|---|---|---|
| 读者站 | <https://sdblog.us.ci> | 读者前台；登录后同一入口进入作者中心 |
| 管理后台 | <https://admin.sdblog.us.ci> | 内容治理、作者后台、系统管理 |
| 图片域 | <https://img.sdblog.us.ci> | 封面与正文配图的对象存储域名，供上面两个入口引用，不是独立应用 |

- 三个入口都由 Cloudflare 边缘提供 HTTPS，回源到本机演示栈。
- 读者站与管理后台各自做服务端反代，后端服务本身不单独对公网开放。
- 读者站与作者中心**共用同一个入口**，用登录状态区分：未登录是读者，登录后顶部可进入「作者中心」。

## 2. 可体验的角色与路径

### 2.1 匿名读者（无需账号）

| 想体验 | 路径 |
|---|---|
| 首页文章流与分页 | `/`、`/page/{n}` |
| 文章详情（目录、代码高亮、上下篇导航、评论列表） | `/post/{slug}` |
| 标签页与标签云 | `/tag/{slug}`、`/tags` |
| 全文搜索（中文分词、命中高亮、深翻页） | `/search` |
| 作者公开主页 | `/user/{userId}` |
| 关于页 | `/about` |

### 2.2 登录用户（读者 + 作者）

注册即登录，注册用户天然具备写作能力，**没有单独的「申请成为作者」流程**。

| 想体验 | 路径 / 入口 |
|---|---|
| 注册 | `/register` |
| 作者中心：我的文章 | `/me` |
| 新建文章（富文本编辑器，支持上传封面与正文图） | `/me/new` |
| 编辑文章（内容变化才产生新版本） | `/me/{id}/edit` |
| 个人资料 | `/me/profile` |
| 发表评论 | 文章详情页评论区 |

作者可对自己的文章执行：发布、隐藏 / 重新公开、删除；也可查看历史版本快照。

### 2.3 管理员

| 想体验 | 菜单位置 |
|---|---|
| 文章治理（他对人文章下线 / 恢复、查看详情与版本） | 博客管理 → 文章治理 |
| 评论审核与删除 | 博客管理 → 评论管理 |
| 标签运营（重命名、合并、精选、排序） | 博客管理 → 标签治理 |
| 我的文章（管理员也可以是作者） | 博客管理 → 我的文章 |
| 系统管理（用户 / 角色 / 菜单 / 字典） | 系统管理 |

> 治理权限以后端权限位为准；非管理员账号登录管理后台看不到治理菜单，即使直接请求接口也会被拒绝。

## 3. 演示数据

演示库装载的是**虚构种子数据**，不是真实用户内容：

- 5 位虚构作者、52 篇文章（其中公共可见 47 篇）、200 条评论、20 个标签。
- 覆盖有/无封面、有/无代码块、单/多标签、草稿/已发布/作者隐藏/管理员下线四种状态的组合。
- 文章正文里的代码块在生成时就已完成语法高亮着色，打开即是彩色。
- 发布时间分散在近 90 天，评论时间均晚于文章时间。
- 配图是抽象的 SVG 占位图，不包含任何真实照片或个人信息。

种子可重复装载（幂等），不会破坏框架自带的管理员账号。

## 4. 体验注意事项

1. **演示账号不公开**。匿名浏览无需账号；需要作者或管理员视角，请通过私下渠道索取独立演示账号（虚构身份、最小权限）。
2. **可以随便写、随便改自己的文章**：演示库就是用来试的，写坏不影响任何人。
3. **不要上传真实个人资料**：头像、昵称、正文都请使用虚构内容；演示环境的数据会被重置。
4. **管理后台的高权限账号不对外提供**；若需验证治理流程，请使用受限演示账号并只做只读浏览。
5. **图片域直连只返回对象本身**，没有目录浏览页；看到 404 属正常。

## 5. 可用性边界

- 演示栈跑在一台开发机的 WSL2 + Docker Compose 上，靠 Cloudflare Tunnel 暴露；**开发机休眠、关机、重启或更新时服务会离线**。
- 因此三个域名会出现无法访问（连接失败或 502）的情况，这属于环境限制，**不承诺 SLA，也不代表项目不可运行**。
- 本文档记录时（2026-11-11）演示栈**处于停止状态**，三个域名均不可用。
- 若需要在本机跑起来自验：三个仓库按后端仓库 `README.md` 的「一键启动」章节，用 Compose 起 7 个服务即可（需要 Java/Maven/Docker，约 3~4GB 内存；ES 可关掉并切到 MySQL 搜索降级）。
